# Kolloid Kimyo — Virtual Laboratoriya Majmuasi

«Kolloid kimyo» fanidan 12 ta interaktiv virtual laboratoriya ishini birlashtiruvchi veb-platforma (sof HTML / CSS / JavaScript, GitHub Pages uchun tayyor).

## Laboratoriya ishlari ro‘yxati

1. **Kolloid eritmalarning kondensatsion usulda olinishi** — oltingugurt va kanifol gidrozollari, $\text{Fe(OH)}_3$ gidrolizi, $\text{AgI}$ zollari
2. **Kolloid sistemalarni disperslash usulida olinishi** — stannat kislota peptizatsiyasi, benzol va pista moyi emulsiyalari
3. **Kolloid sistemalarni tozalash usullari** — oddiy dializ, elektrodializ, ultrafiltratsiya
4. **Dispers sistemalarning elektr xossalari** — elektroforez, zarracha zaryadini aniqlash va elektroforetik harakatchanlik
5. **Kolloid eritmalarning koagullanishi** — jelatinani degidratlash va izoelektrik nuqtani ($\text{pH} \approx 4{,}7$) topish
6. **Gidrofil zollarning koagullanishi** — tuxum oqsilining qaytar tuzlanishi va qaytmas termik denaturatsiyasi
7. **Gidrofob zollarning koagullanishi** — Shultse–Gardi qoidasi, koagullanish ostonasi va ikki kolloidning o‘zaro koagullanishi
8. **Sedimentatsion analiz** — vintli tarozida cho‘kish egri chizig‘i va zarrachalar o‘lcham taqsimlanishi
9. **Kolloid sistemalarda strukturalar** — Ostvald viskozimetrida qovushqoqlik (konsentratsiya, harorat, tuzlar ta’siri)
10. **Dispers sistemalarning sirt hodisalari. Adsorbsiya** — sirka kislota adsorbsiyasi va Freyndlix izotermasi
11. **Qattiq jism sirtidagi adsorbsiya** — $\text{KMnO}_4$ spektrofotometriyasi, Langmyur izotermasi va solishtirma sirt yuzasi
12. **Emulsiyalarning olinishi, tiplari va ko‘piklarning xossalari** — benzol/paxta moyi emulsiyalari hamda nekal va agar-agar ko‘piklari

## Tuzilishi

- `index.html` — asosiy sahifa, bo‘limlar bo‘yicha filtrlash, qidiruv, progress nazorati va interaktiv disperslik shkalasi
- `labs/01-kondensatsion.html` … `labs/12-emulsiya-kopik.html` — har biri mustaqil SVG tajriba stoli, ovoz effektlari, savollar, grafiklar va chop etiladigan hisobotga ega virtual laboratoriyalar
- `assets/` — umumiy stillar, skriptlar va grafik resurslar
